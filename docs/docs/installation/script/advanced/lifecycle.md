# Stopping and starting VVault
You can stop and start VVault easily by using the install script.

## Stop
To stop VVault, run the install script with the `stop` option. This will stop all running VVault containers.

```bash
$ ./install.sh stop
```

## Start
To start VVault, run the install script with the `start` option. This will start all VVault containers.

```bash
$ ./install.sh start
```

## Restart
To restart VVault, run the install script with the `restart` option. This will restart all VVault containers.

```bash
$ ./install.sh restart
```
