# Stopping and starting VelixVault
You can stop and start VelixVault easily by using the install script.

## Stop
To stop VelixVault, run the install script with the `stop` option. This will stop all running VelixVault containers.

```bash
$ ./install.sh stop
```

## Start
To start VelixVault, run the install script with the `start` option. This will start all VelixVault containers.

```bash
$ ./install.sh start
```

## Restart
To restart VelixVault, run the install script with the `restart` option. This will restart all VelixVault containers.

```bash
$ ./install.sh restart
```
