# Mobile Apps

This section contains information about installing and using the VelixVault mobile apps. These mobile apps allow you to manage and use VelixVault from your smartphone enabling autofilling of login credentials via native iOS/Android capabilities.

## Features
You can use the VelixVault mobile apps to:
- Autofill existing alias information on websites the (native) browser
- Generate new aliases
- Access received emails on all of your aliases
- View your aliases and identities

The VelixVault mobile apps work with both the official cloud hosted version of VelixVault but also the self-hosted version.

## Supported Platforms
VelixVault is available on the following mobile platforms. Follow the link for your platform to get started with the installation process:

- [iOS app](./ios/index.md): download from the App Store or build from source
- [Android app](./android/index.md): download from Google Play or build from source
