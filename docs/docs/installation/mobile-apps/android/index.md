# Android app

VVault is not on Google Play or F-Droid yet. Until it is, install the APK directly.

## Install the APK

1. Download the latest APK from the
   [releases page](https://github.com/pgpvieira-code/vvault/releases)
2. Open the file on your device and allow installation from that source when Android asks
3. Open the app and follow the instructions

Android warns about apps installed outside the Play Store. That warning is about the install source,
not about this app — you can verify what you are installing, since the
[full source is public](https://github.com/pgpvieira-code/vvault).

## Get it on Obtainium

[Obtainium](https://obtainium.imranr.dev) installs and auto-updates apps straight from their GitHub
releases, which is the closest thing to a store while VVault is not published on one. Point it at
`https://github.com/pgpvieira-code/vvault` and it will track the releases.

This requires the [Obtainium app](https://github.com/ImranR98/Obtainium) to be installed.

## Build from Source
If you wish to install the mobile app from source instead, see the [build-from-source](build-from-source.md) documentation. This will allow you to make changes to the mobile app and/or to use a specific version of the mobile app.
